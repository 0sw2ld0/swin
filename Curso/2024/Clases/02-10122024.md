# Clase sobre Macros en Swift

## Resumen General

En esta clase se abordó el concepto de macros en Swift, su funcionalidad y cómo se pueden utilizar para mejorar la programación en este lenguaje. Se explicó qué son las macros, cómo permiten reutilizar código antiguo y optimizar su ejecución, así como los diferentes tipos de macros disponibles en Swift. Se discutieron las macros libres y adjuntas, su implementación y ejemplos prácticos. Además, se introdujo el concepto de concurrencia estricta en Swift 6 y cómo afecta a la programación, así como la importancia de los actores y el protocolo Sendable para garantizar la seguridad en el acceso a datos en entornos concurrentes.

## Índice de Contenidos

1. ### ¿Qué es una Macro? (00:00:00)
   **Descripción:** Se definió una macro como una herramienta que permite "swiftificar" el código legacy, facilitando la reutilización de código antiguo sin perder rendimiento. Se explicó que las macros se ejecutan en una capa intermedia entre la compilación y la ejecución, permitiendo validar expresiones que normalmente solo se podrían validar en tiempo de ejecución. Se presentaron dos tipos de macros: las macros libres (freestanding) y las macros adjuntas. Las macros libres se pueden insertar en cualquier parte del código y transforman el código que contienen, mientras que las macros adjuntas están asociadas a una declaración específica y permiten añadir funcionalidad a tipos existentes.

3. ### Implementación de Macros de Expresión DateLiteral (12:00:00)
   **Descripción:** Se explicó cómo crear un paquete especial para macros en Swift, que incluye la declaración de la macro, el código de la macro y pruebas para validar su funcionamiento. Se mostró un ejemplo práctico de creación de una macro de expresión llamada DateLiteral que nos permite convertir una cadena en fecha de manera directa sin que sea opcional y cómo podemos procesar los distintos tipos de macros libres o free-standing.

4. ### Implementación de Macros de Adjuntas (01:08:15)
   **Descripción:** En la clase se realizó un ejemplo práctico de una macro adjunta llamada AutoID. Esta macro permite que cualquier tipo de dato que no sea Identifiable se convierta automáticamente en Identifiable, añadiendo un campo id. La macro se asocia a la declaración de un tipo, como un struct, y permite que se añadan propiedades y métodos a la declaración existente.

4. ### Concurrencia Estricta en Swift 6 (01:54:00)
   **Descripción:** Se introdujo el concepto de concurrencia estricta en Swift 6, que previene problemas de data races al garantizar que los datos no sean accedidos simultáneamente desde diferentes hilos. 

5. ### Problemas en concurrencia (Data races) (02:14:00)
   **Descripción:** Se discutieron los problemas comunes de concurrencia, como el data race, la inversión de prioridad y los deadlocks. La conversación se centra en los data races, por qué se provocan, los errores que pueden generar y entender lo que estamos intentando evitar con el uso de Swift 6.

5. ### El contexto, hilos de ejecución y el protocolo Sendable (02:43:30)
   **Descripción:** Se explica qué es un dominio aislado o contexto y cómo el uso del protocolo Sendable ayuda a garantizar el paso de variables mutables de forma segura entre distintos, siendo el objetivo principal de Swift 6.

5. ### Actores y Actores Globales (03:07:30)
   **Descripción:** Se presentó el concepto de actores en Swift, que son clases que garantizan el aislamiento de sus propiedades y métodos. También los actores globales que aislan de manera global componentes de distintas clases para garantizar la serialización.

### ANEXO: Listado de instrucciones
- **Macros:** Herramientas para definir código dinámico en tiempo de compilación.
- **Macros Libres:** Se pueden insertar en cualquier parte del código.
- **Macros Adjuntas:** Asociadas a declaraciones específicas.
- **Concurrencia Estricta:** Previene data races y asegura el acceso seguro a datos.
- **Actores:** Clases que garantizan el aislamiento de propiedades y métodos.
- **Protocolo Sendable:** Asegura que los datos se pueden pasar de manera segura entre contextos.
- **Actores Globales:** Asegura que los datos de cualquier componente de una clase o struct estén aislados como parte de un actor global.
