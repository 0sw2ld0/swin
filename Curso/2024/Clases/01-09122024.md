# Swift Refresh Workshop, Clase #1 (09/12/2024)

## Resumen General

En esta clase se abordaron los cambios y nuevas funcionalidades introducidas en Swift 6, centrándose en las novedades de los últimos años. Se discutieron conceptos clave como la programación dinámica basada en cambios heredados de Python con llamadas como función y llamadas dinámicas, los property wrappers, result builders, y la importancia de la seguridad en el manejo de datos. Se realizaron ejemplos prácticos para ilustrar cómo implementar estas nuevas características en proyectos reales, y se enfatizó la necesidad de adaptarse a los cambios en el lenguaje para evitar problemas futuros.

## Índice de Contenidos

1. ### Introducción a la Formación (00:00:00)
   Descripción: Se presentó la estructura de la formación, que combina teoría y práctica, y se mencionaron los proyectos que se migrarán de Swift 5 a Swift 6. Se destacó la importancia de entender la concurrencia estricta en Swift 6 y cómo afectará a los desarrolladores.

2. ### Programación dinámica heredada de Python y callAsFunction (00:18:30)
   Descripción: Se explicó cómo podemos usar programación dinámica en Swift que nos permite usar paradigmas muy más prácticos y que no se han usado hasta ahora. Se crea un ejemplo de formateador usando callAsFunction.

3. ### Programación dinámica con DynamicCallable (00:41:42)
   Descripción: Se crea un ejemplo con DynamicCallable que nos permite generar constructores de predicados usando programación dinámica y cómo esta instrucción nos permite trabajar con nombres de parámetros que no existe realmente y son capturados en un par de clave y valor.

4. ### Programación dinámica con DynamicMemberLookup (01:08:15)
   Descripción: Se crea un ejemplo con DynamicMemberLookup que nos permite generar acceder a propiedades que no existen a través de un subscript y con ello, poder crear algoritmos dinámicos que accedan a propiedades creadas en runtime. Se construye un ejemplo de navegador de archivos JSON en formato texto que nos permiten recorrerlos manualmente y que podría ser aplicable a cualquier otro formato a parsear como XML.

5. ### Property Wrappers (01:35:30)
   Descripción: Se introdujeron los property wrappers y su uso en Swift, destacando cómo permiten encapsular la lógica de acceso a propiedades. Se presentó un ejemplo de un property wrapper para acceder al keychain, mostrando cómo se pueden gestionar datos de manera segura y con uso de genéricos para guarar cualquier información, incluso estructuras JSON conformadas con Codable.

6. ### Result Builders (02:56:00)
   Descripción: Se explicó el concepto de result builders y su aplicación en la creación de sintaxis declarativa similar a HTML. Se mostró cómo construir un HTML builder utilizando result builders para generar contenido dinámico de manera estructurada. Se discutió cómo se pueden crear elementos HTML de forma dinámica y cómo se pueden anidar para generar una estructura HTML completa.

7. ### Debate sobre desarrollo web y web estáticas (03:21:30)
   Descripción: A partir de una pregunta se generó un debate sobre la idoneidad del uso de generadores estáticos de HTML (como los creados en el ejemplo de los result builder o el uso de frameworks de frontend web como Angular o Vue, debatiendo sobre ventajas e inconvenientes de cada solución. Se concluye con una versión ampliado del HTML Builder.

## Conclusiones Finales

La clase proporcionó una visión integral de las nuevas características de Swift 6, enfatizando la importancia de adaptarse a los cambios en el lenguaje y cómo estos pueden mejorar la seguridad y la eficiencia en el desarrollo de aplicaciones. Los ejemplos prácticos ayudaron a consolidar el aprendizaje y a preparar a los estudiantes para implementar estas nuevas funcionalidades en sus proyectos.

### ANEXO: Listado de instrucciones
- CallAsFunction: Permite llamar a instancias como funciones incentivan la programación dinámica.
- DynamicCallable: Podemos recibir parámetros que no existen como una tupla de valores y construir soluciones dinámicas.
- DynamicMemberLookup: Permite acceder a propiedades de una instancia que no existen a través de un subscript.
- Property Wrappers: Permiten encapsular la lógica de acceso a propiedades, facilitando la gestión de datos.
- Result Builders: Facilitan la creación de sintaxis declarativa, permitiendo construir estructuras complejas de manera sencilla.
